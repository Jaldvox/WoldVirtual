## 🌟 Visión del Proyecto

**WoldVirtual Crypto 3D** representa la convergencia entre el metaverso inmersivo y la tecnología blockchain descentralizada. Esta plataforma pionera combina renderizado 3D de vanguardia con React 18+, Three.js, y integración nativa de blockchain para crear experiencias digitales sin precedentes.

### 🎯 Misión
Democratizar el acceso al metaverso mediante una arquitectura escalable, tecnología de código abierto y una economía digital transparente basada en blockchain.

### 🎮 **ThreeCanvas.jsx - Motor 3D**
```jsx
// src/components/Three/ThreeCanvas.jsx
import React, { useRef, useEffect, useState } from 'react';
import * as THREE from 'three';

/**
 * Three.js Canvas Component
 * Características: WebGL Rendering, Animation Loop, Memory Management
 * Performance: 60fps con geometría optimizada
 */
const ThreeCanvas = () => {
  const mountRef = useRef(null);
  const [scene, setScene] = useState(null);
  const [renderer, setRenderer] = useState(null);
  const [camera, setCamera] = useState(null);

  useEffect(() => {
    if (!mountRef.current) return;

    // Inicialización optimizada de la escena
    const newScene = new THREE.Scene();
    newScene.background = new THREE.Color(0x1a1a2e);

    // Configuración de cámara con FOV óptimo
    const newCamera = new THREE.PerspectiveCamera(
      75,
      mountRef.current.clientWidth / mountRef.current.clientHeight,
      0.1,
      1000
    );
    newCamera.position.set(0, 0, 5);

    // Renderizador con antialiasing y optimizaciones
    const newRenderer = new THREE.WebGLRenderer({ 
      antialias: true,
      alpha: true,
      powerPreference: "high-performance"
    });
    newRenderer.setSize(
      mountRef.current.clientWidth,
      mountRef.current.clientHeight
    );
    newRenderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
    mountRef.current.appendChild(newRenderer.domElement);

    // Geometría de demostración - Cubo con material holográfico
    const geometry = new THREE.BoxGeometry(1, 1, 1);
    const material = new THREE.MeshBasicMaterial({ 
      color: 0x00ff00,
      wireframe: true,
      transparent: true,
      opacity: 0.8
    });
    const cube = new THREE.Mesh(geometry, material);
    newScene.add(cube);

    // Iluminación ambiental
    const ambientLight = new THREE.AmbientLight(0x404040, 0.6);
    newScene.add(ambientLight);

    // Loop de animación optimizado
    const animate = () => {
      requestAnimationFrame(animate);
      
      // Rotación suave
      cube.rotation.x += 0.005;
      cube.rotation.y += 0.005;
      
      newRenderer.render(newScene, newCamera);
    };
    animate();

    // Estado local
    setScene(newScene);
    setRenderer(newRenderer);
    setCamera(newCamera);

    // Cleanup para prevenir memory leaks
    return () => {
      if (mountRef.current && newRenderer.domElement) {
        mountRef.current.removeChild(newRenderer.domElement);
      }
      newRenderer.dispose();
      geometry.dispose();
      material.dispose();
    };
  }, []);

  return (
    <div 
      ref={mountRef} 
      className="three-canvas"
      style={{ 
        width: '100%', 
        height: '600px', 
        border: '2px solid #00ff00',
        borderRadius: '12px',
        boxShadow: '0 0 20px rgba(0, 255, 0, 0.3)'
      }}
    />
  );
};

export default ThreeCanvas;
```

## 🚀 Instrucciones de Desarrollo

### **⚡ Inicio Rápido**

```bash
# 1. Clonar el repositorio
git clone https://github.com/Chicook/WoldVirtual_Crypto_3Dv1.git

# 2. Navegar al directorio del proyecto
cd WoldVirtual_Crypto_3Dv1/ThreejsWebgl

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Abrir en navegador: http://localhost:5173
```

### **🛠️ Scripts Disponibles**

| Comando | Descripción | Uso |

| `npm run dev` | Servidor de desarrollo con HMR | Desarrollo local |
| `npm run build` | Build optimizado para producción | Despliegue |
| `npm run preview` | Preview del build de producción | Testing pre-deploy |
| `npm run lint` | Análisis de código con ESLint | Control de calidad |
| `npm run lint:fix` | Corrección automática de linting | Mantenimiento |
