## 🎯 Descripción General

Wold Virtual es un proyecto innovador de metaverso basado en blockchain que está redefiniendo la interacción digital. Nuestra plataforma integra tecnología blockchain, inteligencia artificial y sistemas descentralizados para crear experiencias inmersivas y seguras.

### 🌟 Características Principales

- **Criptomoneda**: WoldcoinVirtual (WLCV) con suministro máximo de 30.000.000.000 WLCV
- **Comisiones**: Variables según la red (Ethereum, BSC, Polygon, etc.)
- **Formato de saldo**: "0,000" para el metaverso
- **Protocolo de recompensas**: Garantiza mínimo 50% de recompensas
- **Prueba de trabajo**: Segunda capa de seguridad con renderizado en tiempo real

## 🚀 Instalación y Configuración

### Requisitos Previos
- Python 3.x
- Node.js
- Compilador de Solidity
- Web3.js
- Flask

### Instalación Rápida

```bash
# Clonar el repositorio
git clone https://github.com/Chicook/WoldVirtual.git
cd WoldVirtual.0.0.1

# Instalar dependencias de Python
pip install flask flask_socketio psycopg2-binary web3

# Instalar dependencias de Node.js
npm install
```

### Instalación con Entorno Virtual (Recomendado)

```bash
# Crear entorno virtual
python -m venv venv

# Activar entorno virtual
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Instalar dependencias
pip install -r requirements.txt
```

## 🧪 Testing y Desarrollo

### Configuración de Pruebas ✅ FUNCIONANDO

El proyecto incluye un sistema completo de pruebas automatizadas:

```bash
# Ejecutar todas las pruebas
pytest

# Ejecutar con detalles
pytest -v

# Ejecutar con cobertura de código
pytest --cov=bakup/copia_de_seguridad/WoldVirtual_Crypto_3D

# Generar reporte HTML de cobertura
pytest --cov --cov-report=html
```

### Dependencias de Testing

```bash
# Instalación mínima para pruebas
pip install pytest pytest-asyncio pytest-mock pytest-cov

# Instalación completa
pip install pytest==7.4.3 pytest-asyncio==0.21.1 pytest-mock==3.12.0 pytest-cov==4.1.0
```
